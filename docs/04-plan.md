## 1. 全局约束与验收解释

### 本轮表现层定案

取消复杂角色人偶立体建模，不再绘制13名角色的人体、五官、发型与服饰模型。角色视觉统一由CharacterTokenRenderer呈现为《原神》风格鎏金悬浮角色名字铭牌／元素神之眼棋子信标；40阶2.5D直线天梯地图（0～40共41个阶位）、选角台、图鉴页和结算弹窗共用同一角色规格。

1. **开始门槛：** 前一轮有用户验收确认，当前轮获得开发授权；只实现本轮范围。

3. **运行说明：** 每轮提供实际可运行命令、入口、前置账号/角色/夹具与AC样例。沿用`npm run dev`、`npm run build`、`npm test`，按迭代扩展Node规则/隐私测试与浏览器集成夹具；真实浏览器验证Canvas/SVG/CSS渲染、信标标识与状态动画、音频与交互。文档更新不声称已执行这些检查。
4. **人工反馈：** `docs/acceptance/iteration-NN.md`记录版本、环境、操作、对应AC/子项、预期/实际、证据和待修问题；不伪造未执行的浏览器或音频测试结果。

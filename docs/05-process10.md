## 验收边界

联机限定同一浏览器同源窗口，需要 BroadcastChannel、LocalStorage、Web Locks；没有跨设备服务器或断线续局。页面关闭通知由浏览器尽力发送，生命周期锁用于确认已观察到的会话结束，不把心跳变慢判负。实际关闭识别速度、并发加入、结果广播与关闭竞争需要按上表复验。当前AI是启发式策略，不保证困难固定胜率。全量验收前保留“待用户验收”状态。

## 2026-10-31 反馈修复：房主就绪后仍显示大厅

原因：房主最后就绪时，NetworkManager.ready内启动比赛并同步通知视图进入选角；点击处理器await返回后又无条件调用renderOnline，覆盖了选角DOM，而视图pageKey已是opening，造成两端画面不一致。

修复：GameView房间按钮改为handleRoomAction，只提交操作，由Game订阅驱动渲染；renderOnline增加当前页面及进行中比赛检查，防止过期调用覆盖选角/首页；异步错误反馈兼容原提示节点已卸载的情况。没有修改房间同步协议或规则。

新增tests/unit/room-lobby-transition.test.js共5项回归：房主后就绪、房主先就绪及重复通知、异步回调恢复前比赛已启动、退出后的首页保护、大厅渲染保护。保留实施脚本fix-room-lobby.mjs。npm test：120/120通过；npm run build通过。未删除文件。测试使用真实Game/NetworkManager阶段逻辑并模拟DOM绘制，未执行真实双窗口浏览器复验。

# 迭代2：Canvas 2.5D 登山天梯实现与人工验收

更新：2026-10-29。当前状态：开发者检查中，待用户人工验收。旧 Three.js 验收及截图仅为历史记录，不代表本次 Canvas 版本。

## 本轮交付

- 同一 Vite 工程中替换 MountainMapRenderer：HTML5 Canvas 2D 透视投影、0～40阶笔直天梯、台面/前立面/侧面、砖缝、金边、分区及编号。
- 山林、冰雪、白玉浮空阶与终点发光门廊/神座；左右三层残柱、金箍、断梁；流云、斜射光束和星芒。
- CSS3 独立远近云层和光束，根据镜头中心产生不同位移；减少动态效果设置生效。
- 复用地图详情面板、首页路由、本地账号及跟随偏好；五个焦点、拖拽、缩放、点击/键盘选阶。
- 每阶展示空槽和站立锚点，端点仍为不可布雷保留区；P1/P2只是公开位置标记，无角色图鉴或对战逻辑。

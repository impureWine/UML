# 迭代2：40阶登山地图UI实施与人工验收

**日期：** 2026-10-28  
**状态：** 开发者检查完成，待用户人工验收。迭代1已由用户确认通过；本轮未进入迭代3。

## 1. 本轮交付

遵循 `03-design.md` 第7.2节与 `04-plan.md` 第5节，用 Three.js/WebGL 实现真正的立体地图。0～40共41阶沿同一笔直轴线向上，山体、树林、雪峰、云海与浮岛提供山路的空间层次，不改变已确认的阶位拓扑。

- 0阶山脚营地、1～15阶蒙德苍翠山林、16～30阶龙脊雪山、31～39阶星穹玉阶、40阶天空岛门廊与王座；采用程序化低多边形场景、白昼青绿/冰蓝/象牙金配色。
- 每阶有厚度、正面与顶面、编号；0/10/20/30/40采用金色关键平台。1～39有一致的通用布雷槽位，0和40禁布雷；槽位不表达是否有雷。
- 画布支持拖拽、滚轮和按钮缩放、山脚/山顶/P1/P2/全局五种聚焦；相机按时间平滑插值。点击台阶实体或编号显示选阶详情，提供分区导航、阶号输入、前后阶、定位与键盘选阶。
- P1/P2仅为公开位置的抽象席位信标，同阶时左右分开；跟随开关复用当前账号的偏好存储。默认预览中两席均在0阶。
- 三个对战入口共享地图预览；返回首页、切换账号和重载会释放旧场景。WebGL失败提供提示和恢复入口。

本轮没有角色模型、真实对局、布雷操作、手牌、伤害、AI决策或联机房间；图鉴、完整设置和音乐仍按原迭代安排推进。未删除任何文件。

## 3. 开发者检查结果

- `npm.cmd test`：**40项通过，0失败**。
- `npm.cmd run build`：通过。Three.js地图模块动态加载，产物约553.11kB（gzip约140.96kB），Vite保留大于500kB的体积提示；首页脚本约57.60kB。该提示不影响运行，未通过提高阈值隐藏。
- 内置Chromium 156中，1366×768、1920×1080均通过**21项地图夹具断言**，包括41阶编号可见、互不遮叠和75%最小缩放可读性。
- 实际操作验证：五聚焦、实体台阶点击、拖拽不误选、滚轮、键盘跨屏选阶、WebGL中断提示及重载恢复。独立审查发现的编号重叠、同阶标签重叠与键盘焦点问题均已修正。
- 120帧采样：1366×768约198.3FPS，帧间隔p95约5.2ms；1920×1080约189.0FPS，p95约5.3ms；选阶同步处理均约0.50ms，195次绘制调用。仅代表本次内置浏览器环境，不等同于物理屏幕刷新率或端到端可见反馈；四浏览器全量兼容性留待迭代10。

完整操作证据、限制与截图见[本轮验证记录](acceptance/iteration-02.md)。开发者检查不代替下面的用户验收。

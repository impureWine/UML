# 迭代1实施核对计划

**Goal：** 完成可启动的本地账号系统与首页导航，仅交付迭代1。
**Architecture：** 沿用 View / Controller / Model / Utils；Game 管理 AUTH/HOME 与占位导航，AccountManager 协调账号，LocalStorageStore 单键事务持久化。身份仅存窗口内存。
**Tech Stack：** JavaScript ES Modules、Vite、Node 内置测试、LocalStorage、Web Crypto PBKDF2、Web Locks。
**Spec：** `docs/03-design.md` 第4、7、10节；`docs/04-plan.md` 第4节。用户本轮已明确授权实施。

## 约束

- 不删除文件；不实现迭代2及后续功能。
- 用户名2～16位字母、数字、中文且区分大小写，密码至少4位；注册后仍需显式登录。
- 存储键 `climb40.accounts.v1`，命名 Web Lock 内重读并一次写入；失败不覆盖原数据、不伪报成功。
- 不持久化登录身份、未完局，不造战绩；12常规角色默认可用，隐藏融合初始锁定。
- 五个子页内部仅占位；播放器仅标明占位。

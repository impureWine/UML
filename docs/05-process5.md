## 实现与文件

- `src/controller/Game.js`：唯一准备门禁、先手依次保密锁定、步骤token拒绝旧操作、两向兑换、部署/移动/撤回、齐锁进入第1回合CARD_LOCK，提交落脚结算。
- `src/model/Bomb.js`、`MountainBoard.js`、`StepCell.js`：带归属实体雷、同阶bombQueue及本人场上数量查询；0/40禁布。
- `src/model/CardLedger.js`：90张实体牌分区追踪；初选/抽牌转移及兑换秘密销毁；守恒断言。
- `src/model/JudgeRule.js`、`BattleLog.js`：纯计算敌雷优先、稳定ID选雷、单次1雷、回退10至0的连锁；Game统一移除炸弹、提交站位和归属公开事件。预留免疫与回退距离钩子，后续角色能力轮接入。
- `src/utils/InformationProjector.js`：己方资源副本、遮罩期间清私有信息、齐锁公开库分项与双方手牌数；地图地形投影不携带bombQueue。
- `src/view/OpeningPanel.js`、新增`PreparationPanel.js`：兑换实体牌勾选、地图点击布雷/移雷/撤回、不可撤销锁定、按住显己雷，释放/取消/失焦/切后台隐藏。
- `src/view/MountainMapRenderer.js`、`src/styles/opening.css`：己雷授权标记、冲击波及逐次受击滑退、准备操作保留镜头；缩小阶号命中区并覆盖开局按钮padding，防止远端阶号重叠错选。
- `tests/unit/preparation-rules.test.js`：6组规则/隐私/守恒测试；`tests/unit/mountain-board.test.js`更新领域阶位队列契约；新增`tests/fixtures/preparation-preview.html`内存验收入口。
- `docs/PROGRESS.md`及本文件：状态与人工验收清单。

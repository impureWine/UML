## 1. 启动与检查

需要 Node.js 22.12.0及以上版本。当前工作区依赖已安装，在项目根目录运行：

```powershell
npm run dev
```

打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。若该服务已经运行，可直接访问；固定端口已被占用时不会静默换端口。新环境先运行 `npm install`。不要直接双击 `index.html`。

| 命令 | 作用 |
| --- | --- |
| `npm test` | 执行Node内置测试，包括账号、存储与导航 |
| `npm run build` | 构建至`dist/`，不清空已有构建文件 |
| `npm run preview` | 预览已构建文件，地址为`http://127.0.0.1:4173/` |

账号属于当前浏览器配置文件和当前源。5173与4173端口、`localhost`与`127.0.0.1`分别是不同源，账号不会自动共享。后续验收固定使用同一个地址。账号保留在LocalStorage中，当前登录身份只存在窗口内存里，刷新后重新登录。

## 2. 本轮实现与边界

- 完成 View / Controller / Model / Utils 四层最小可运行装配。Game只编排AUTH/HOME和五个占位页面，不运行对局。
- AccountManager支持注册、口令校验、切换、退出以及按账号读取统计、历史、解锁和偏好。注册成功后仍需显式登录。
- 用户名须为2～16位英文字母、数字或中文，区分大小写，不接受空格；密码至少4个字符，不裁剪前后空格。
- 凭据采用独立随机salt和PBKDF2-SHA256（210000次）派生校验，不保存明文密码。该工作量的跨浏览器耗时尚未量化。
- LocalStorage使用单一版本化键`climb40.accounts.v1`，在命名Web Lock内重读、校验并一次写入。写入失败、损坏档案或缺少能力均明确报错，保留原数据。
- 首页为白昼天空岛、星轨与圣殿视觉。顶部常驻账号名、总局数/胜/负/平、隐藏角色锁态及切号/退出入口；展示完整历史和可展开的已解锁角色名单。
- 新账号零战绩、空历史，CH-01～CH-12默认可用，CH-13“莱茵多特/纳贝里士”锁定。已保存的合法历史按时间降序展示双方角色/阶数、本人席位、结果、结束时间和原因。
- “本地双人对战”“AI对战”“联机对战”“角色与规则图鉴”“设置”均可打开对应占位页并返回首页。播放器为明确禁用占位。

本轮没有3D天梯、角色模型、选角、出牌、战绩生成、解锁操作、AI决策、联机房间、实际音频或可编辑设置页。Settings仅为隔离保存和后续接线提供数据结构。首页图形为SVG/CSS装饰，不是迭代2地图。测试夹具中的历史与解锁样例不属于真实战绩。

### 5.1 注册、登录和错误反馈

- [x] 首次打开页面出现登录框，不能绕过登录操作首页；登录框可切到注册。

# 迭代7：基础角色技能组件

日期：2026-10-31。迭代1～6已由用户人工验收；本轮开发完成，待用户人工验收。

## 实施与规则口径

Character组合独立SkillComponent列表，组件保留sourceOrigin、isSuppressed，主动次数独立。初始化按对手压制组件设置生命来源压制。Game协调资源及结算，投影仅提供当前席私有技能信息。

本轮用户要求优先于旧设计中两处不同口径：冻结按基础与被动相加后的总步数减半向上取整；空间分支A可选择任意已存在炸弹，保留归属。空间选择列表只给编号和阶位，不给归属；成功才扣次数，无选择预扣，取消或未提交不耗次。终焉宣告要求操作前至少2张手牌。

RoundSnapshot恢复牌库、牌账本（含秘密销毁和公开牌）、双方牌/位置/库存、场雷、普通技能次数、护盾、连胜、风首次状态、有效记录。时之回溯在结算展示结束后提供5秒窗口；当轮候选登顶/耗尽未确认、不写战绩。时间已耗次数保留，旧令牌失效，同回合重新操作。

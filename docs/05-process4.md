# 迭代4：开局选角、硬币与交替初选

日期：2026-10-29。迭代1～3已由用户确认通过；本轮开发完成，待人工验收。

## 实现与范围

首页本地/AI入口仍保留既有地图预览，点击“开始本轮对局 · 选择角色”进入开局。两席独立铭牌、元素与技能摘要复用角色目录和CharacterTokenRenderer；允许同角色。P1为主账号，P2为访客或手动配置AI，共享主账号已解锁池。难度与手动角色保存在当前开局配置中，本轮不执行AI策略。

测试解锁/重置只修改当前账号CH-13及revision，通过原有存储排他锁持久化，不改统计/历史。重置清空未确认融合选择；角色确认后禁止测试修改。解锁条件显示“主账号使用莱茵多特正式战胜纳贝里士”，真实胜利解锁属后续迭代。

CSS双面硬币提供神像/徽记、透视翻转与落面；Web Crypto均匀位决定P1/P2，非二次幂索引采用拒绝采样。90张牌具有唯一cardId，手选每次取1张后强制交接；快捷键1/2/3可取石头/剪刀/布。每次清除上一席手牌DOM与快照，接手后只加载当前席私有手牌。不展示库花色分项或敌手牌栏。快速补齐按既定交替逐张抽剩余实体，保留手选。双方各30后库余30，自动到开局准备到达视图。无返回初选按钮；兑换/布雷/准备锁定待迭代5。

默认初始化0阶、3雷/上限4；巴尔泽布4雷/上限5。账号从选角起锁定，退出开局需确认并返回首页，无战绩写入。

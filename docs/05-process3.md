# 迭代3：角色名字铭牌信标与角色规则图鉴

日期：2026-10-29（Asia/Hong_Kong）。状态：开发完成，待用户人工验收。迭代2已由用户确认验收；本轮不进入迭代4。

## 本轮实现与文件

- `src/resources/characters.js`：13名角色全名、称号、阵营、主题色、独立SVG徽记、20种技能说明；融合复用黄金与生命四项资料。
- `src/view/CharacterTokenRenderer.js`：共用鎏金悬浮铭牌、席位/预览标识、双色融合与双徽记、阴影及元素法阵。
- `src/view/CharacterAnimations.js`：Idle / Climb / Hit / Skill状态，有限动画结束回Idle，重播/切换覆盖旧状态。
- `src/view/CharacterGuide.js`：左侧13角色目录，右侧大型铭牌、四态纯视觉预览、阵营、主被动规则、核心规则和融合账号锁态。
- `src/view/GameView.js`、`src/main.js`：首页图鉴接线、样式加载、页面退出释放动画和事件。
- `src/view/MountainMapRenderer.js`：原Canvas台阶上方共用SVG铭牌层；固定屏幕字号，同阶及相近高度左右排列，镜头投影同步；预览攀爬抛物线/退阶轨迹。
- `src/view/MountainMapPanel.js`：P1/P2各13角色与0～40整数阶位输入；应用站位、P1攀爬1阶/受击退10阶/元素光效按钮。所有控件仅作用于内存预览。
- `src/styles/characters.css`：铭牌、图鉴、挂载控件、融合流光、响应式及减少动态偏好。
- `tests/unit/character-token.test.js`、`tests/fixtures/character-preview.html`：目录/状态测试与无账号存储的浏览器夹具。
- `docs/PROGRESS.md`、本文：进度与人工验收。
- 根目录四份 `*-iteration3.py` 为本轮生成/接线辅助记录，保留不删除；不参与应用运行。`dist`由生产构建生成，保留旧产物，未执行清空。

## 2026-10-29 缩放要求更正（以本条为准）

用户澄清：人物立牌应随地图缩小而缩小，而非固定屏幕尺寸。现以500%时210×113px牌面为基准，对整个立牌应用`当前平滑镜头缩放 / 5`的统一缩放；名字、徽记、阶数、阴影和动画一并缩放，双席间距及悬浮留白同步缩放。100%时为基准的1/5，250%时为1/2，500%时保持基准大小。图鉴预览不受地图缩放影响。之前固定尺寸相关记录仅为历史，已被本条替代。

人工复验：同一站位由500%逐渐缩至100%，确认立牌及文字/徽记同步缩小，P1/P2间距同步收缩且不重叠，500%时与原参考效果一致。

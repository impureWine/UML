# 40阶登山博弈

迭代2：在本地多账号与首页导航基础上，提供0～40阶 Three.js 立体登山地图预览。迭代1已通过用户人工验收，迭代2待人工验收。

## 启动

需要 Node.js **22.12.0或更高版本**。当前工作区已安装依赖，在项目根目录运行：

```powershell
npm run dev
```

浏览器打开 [http://127.0.0.1:5173/](http://127.0.0.1:5173/)。新环境先运行 `npm install`，再启动开发服务。请通过本机服务访问，勿直接双击 `index.html`。

## 检查与构建

| 命令 | 用途 |
| --- | --- |
| `npm test` | 使用Node内置测试运行器执行测试 |
| `npm run build` | 构建生产文件至 `dist`，保留目录中已有文件 |
| `npm run preview` | 预览已构建的文件，地址为 [http://127.0.0.1:4173/](http://127.0.0.1:4173/) |

预览前先执行构建。开发服务5173端口与预览服务4173端口属于不同源，LocalStorage账号数据彼此隔离；在预览地址需单独注册。浏览器、浏览器配置文件或地址域名不同，也可能使用不同的数据空间。

## 账号使用

用户名为2–16位中文、英文字母或数字，区分大小写；密码至少4个字符。注册成功后仍需显式登录。刷新页面会回到登录框，请重新登录已有账号。

账号档案保存在当前浏览器、当前源的本地存储中。切号会装载该账号自己的统计、历史、角色解锁与偏好；同源其他窗口切号不会替本窗口登录或退出。存储异常会明确提示失败，可修复浏览器存储条件后重试。

## 本轮范围

登录后进入“本地双人对战”“AI对战”或“联机对战”，可查看同一套地图预览：41阶沿笔直上升轴线布局，依次经过山脚营地、蒙德山林、龙脊雪山云海、星穹天梯与天空岛神座。地图支持拖拽平移、滚轮及按钮缩放、山脚/山顶/P1/P2/全局聚焦、点击与键盘选阶、阶位详情及账号独立的镜头跟随偏好。

P1/P2仅为抽象席位位置标识，槽位仅表示可布置位置。本轮只实现地图UI，角色模型与对战逻辑尚未开始；AI、联机、完整图鉴、设置页与音频仍待后续迭代。

开发服务下可访问[地图验收夹具](http://127.0.0.1:5173/tests/fixtures/map-preview.html)，使用内存中的A/B测试账号检查同阶/分阶位置、镜头、资源释放及性能，不读取或写入真实账号的LocalStorage。
